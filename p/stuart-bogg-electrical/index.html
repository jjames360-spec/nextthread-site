Something’s gone wrong?

Pick what’s happening. You get the safe first steps straight away, and Stuart’s number if you need him.

  1. Find your fuse board. One switch will be down, or sitting halfway.
  2. Unplug everything in the rooms that have gone off, then push the switch firmly back up.
  3. If it stays up, plug things back in one at a time. Whatever trips it again is the culprit, so leave that unplugged.
  4. If it won’t stay up with everything unplugged, leave it off. That is a wiring fault and it needs us.
  1. Look outside. If the neighbours or the street lights are off too, it’s a power cut. Call 105, free, to report it and get updates.
  2. If it’s only you, check the main switch on your fuse board. If it has tripped, push it back up once.
  3. On a pay-as-you-go meter? Check it hasn’t run out of credit.
  4. If the main switch trips again, leave it off and ring us.

Smoke or flames? Get everyone out and call 999.

  1. Stop using it now. Don’t touch a socket or switch that is hot or blackened.
  2. Turn that circuit off at the fuse board. If you’re not sure which one it is, turn the main switch off.
  3. Don’t switch it back on to see if it has cleared.
  4. Ring us today. This is one to deal with the same day.
  1. One light only? Switch it off, let the bulb cool, and check it is seated properly. Then try a new bulb.
  2. LED bulbs on an older dimmer switch often flicker. A dimmer made for LEDs cures it, and that’s a quick job for us.
  3. Several rooms flickering together, or lights that dip when the kettle goes on, can mean a loose connection. Get that looked at soon.
  1. Keep away from wet sockets, switches and light fittings, and keep everyone else away too.
  2. If you can get to the fuse board without standing in water, and your hands are dry, turn the main switch off.
  3. Leave it off until it has been checked, even if things look dry again.
  4. Ring us and we’ll test it before anything goes back on.

If someone is hurt or unwell after a shock, call 999.

  1. Stop using whatever gave the shock. If it’s an appliance, switch it off at the wall and unplug it.
  2. A tingle from a tap, a radiator or the shower is never normal. It points to an earthing fault.
  3. Ring us the same day so we can test the house properly.
